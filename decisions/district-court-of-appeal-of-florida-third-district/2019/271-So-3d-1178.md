# State v. Freixa

## Majority (PER CURIAM.)

PER CURIAM.
Affirmed. See State v. Lewars, 259 So.3d 793 (Fla. 2018) (explaining that section 775.082(9)(a)(1), Fla. Stat. (2012), unambiguously supports the conclusion that "release from a county jail does not satisfy the 'released from' element of the statute's [prison release reoffender] definition").
