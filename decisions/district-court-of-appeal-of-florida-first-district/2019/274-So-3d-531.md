# Miller v. State

## Majority (Per Curiam.)

Per Curiam.
This is an appeal from an order that was the subject of a prior appeal in case number 1D17-3773, which resulted in an affirmance without opinion. Miller v. State , 1D17-3773, 2019 WL 764218 (Fla. 1st DCA Feb. 21, 2019) (table). Since Appellant is not entitled to a second review of the same order, this duplicative appeal is dismissed.
DISMISSED .
