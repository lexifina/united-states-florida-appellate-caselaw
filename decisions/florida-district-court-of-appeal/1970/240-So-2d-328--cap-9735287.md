# Settle v. State

## Majority (PER CURIAM.)

PER CURIAM.
This is the second time this case has been before this court on the same assignment of error. Settle v. State, Fla.App.1969, 223 So.2d 385. In this appeal the public defender has filed an “Anders” brief, and asks permission to withdraw as counsel. We see no reason for the procedure set out in Leone v. State to be followed. Therefore, the order appealed from is affirmed and the public defender’s motion to withdraw is granted.
Affirmed.
HOBSON, C. J., and LILES and Mc-NULTY, JJ., concur.
