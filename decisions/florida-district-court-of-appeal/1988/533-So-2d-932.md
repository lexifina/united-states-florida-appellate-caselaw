# Forness v. State

## Majority (PER CURIAM.)

PER CURIAM.
There is no competent, substantial evidence in this record which supports appellant's involuntary commitment. Schexnay-der v. State, 495 So.2d 850 (Fla. 1st DCA 1986). The order of involuntary commitment is REVERSED.
SMITH, C.J., and ZEHMER and BARFIELD, JJ., concur.
