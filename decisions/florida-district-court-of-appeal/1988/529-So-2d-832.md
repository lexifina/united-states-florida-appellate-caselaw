# State v. Solari

## Majority (PER CURIAM.)

PER CURIAM.
These are consolidated appeals. We affirm the defendant’s appeal. See State v. Hunwick, 446 So.2d 214 (Fla. 4th DCA 1984); Frank v. State, 199 So.2d 117 (Fla. 1st DCA 1967). We reverse the state’s appeal. See State v. Alford, 395 So.2d 201 (Fla. 4th DCA 1981).
GLICKSTEIN and DELL, JJ., and COOK, JACK H., Associate Judge, concur.
