# Rowan v. State

## Majority (PER CURIAM.)

PER CURIAM.
We reverse the sentence imposed by the trial court for failure to enter a written order supporting the guideline departure. See State v. Boynton, 478 So.2d 351 (Fla.1985), cert. denied, 475 U.S. 1029, 106 S.Ct. 1232, 89 L.Ed.2d 341 (1986).
GLICKSTEIN, GUNTHER and STONE, JJ., concur.
