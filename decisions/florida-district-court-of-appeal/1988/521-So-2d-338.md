# Boddie v. State

## Majority (PER CURIAM.)

PER CURIAM.
The record contains sufficient evidence to support the trial court’s order denying appellant’s motion to suppress. See Medina v. State, 466 So.2d 1046 (Fla.1985); McNamara v. State, 357 So.2d 410 (Fla.1978).
AFFIRMED.
ANSTEAD, DELL and STONE, JJ., concur.
