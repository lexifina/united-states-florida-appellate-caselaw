# Vittorio v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm appellant’s convictions and sentence. See Yisrael v. State, 938 So.2d 546 (Fla. 4th DCA 2006), rev. granted, 956 So.2d 458 (Fla.2007). As we did in Yisrael, we certify conflict with Gray v. State, 910 So.2d 867 (Fla. 1st DCA 2005).
GUNTHER, WARNER and GROSS, JJ., concur.
