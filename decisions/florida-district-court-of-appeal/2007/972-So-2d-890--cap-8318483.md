# Kennedy v. State

## Majority (PER CURIAM.)

PER CURIAM.
Robert Kennedy filed this action as an appeal. However, because Kennedy is challenging an order denying a public records request, it is more properly treated as a petition for writ of certiorari. See Yanke v. State, 588 So.2d 4, 5 (Fla. 2d DCA 1991) (treating an appeal from an order denying a request for free copies of a state attorney’s files as a petition for writ of certiorari). The petition is hereby denied without discussion.
DENIED.
BARFIELD, DAVIS, and LEWIS, JJ., concur.
