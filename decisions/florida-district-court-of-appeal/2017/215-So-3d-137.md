# Molina v. State

## Majority (LAGOA, J.)

LAGOA, J.
Juan J. Molina appeals the trial court’s order denying his motion to correct an illegal sentence. We affirm. We write only to commend the trial court on its well-written order, which facilitated this Court’s review.
