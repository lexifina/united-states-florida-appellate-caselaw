# State v. Guffey

## Majority (Per Curiam.)

Per Curiam.
The petition for writ of prohibition is granted, and the order precluding the state from seeking the death penalty is quashed. State v. Lopez, 219 So.3d 865 (Fla. 4th DCA 2017); State v. Chapman, No. 4D17-428, 227 So.3d 626, 2017 WL 3727098 (Fla. 4th DCA Aug. 30, 2017).
Petition granted.
Gerber, C.J., Ciklin and Conner, JJ., concur.
