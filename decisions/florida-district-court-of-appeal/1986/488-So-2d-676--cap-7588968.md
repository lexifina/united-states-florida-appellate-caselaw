# Alexander v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm the conviction but reverse the sentencing order with directions to make the sentences concurrent rather than consecutive. See State v. Davis, 477 So.2d 565 (Fla.1985).
ANSTEAD and DELL, JJ., and SALMON, MICHAEL H., Associate Judge, concur.
