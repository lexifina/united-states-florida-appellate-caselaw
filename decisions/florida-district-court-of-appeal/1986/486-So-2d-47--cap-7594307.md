# Matthews v. State

## Majority (DAUKSCH, Judge.)

DAUKSCH, Judge.
This is an appeal from a sentence. Because the trial court departed from the recommended guideline sentence without giving contemporaneous written reasons for the departure we quash the sentence and remand for resentencing. State v. Jackson, 478 So.2d 1054 (Fla.1985); State v. Oden, 478 So.2d 51 (Fla.1985).
SENTENCE QUASHED; REMANDED.
COBB, C.J., and ORFINGER, J., concur.
