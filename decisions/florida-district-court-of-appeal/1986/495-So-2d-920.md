# Coleman v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm appellant’s conviction but re-mand with direction to strike costs from the written judgment or conduct a hearing in accordance with Jenkins v. State, 444 So.2d 947 (Fla.1984), should the State request same within thirty days.
GLICKSTEIN, DELL and STONE, JJ„ concur.
