# Arnold v. Shoher

## Majority (PER CURIAM.)

PER CURIAM.
Appellant raises two issues. We affirm as to the first because there is substantial, competent evidence to sustain the action of the trial court. We affirm as to the second because appellant did not raise the issue in the trial court.
LETTS, GLICKSTEIN and WALDEN, JJ., concur.
