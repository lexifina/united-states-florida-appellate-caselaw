# Sanchez v. State

## Majority (PER CURIAM.)

PER CURIAM.
We dismiss this appeal for lack of jurisdiction. See Dawson-Knapp v. State, 679 So.2d 1 (Fla. 2d DCA 1995). This denial is without prejudice to Mr. Sanchez’s right to file any timely and appropriate postconviction motion. See Lawton v. State, 731 So.2d 60 (Fla. 2d DCA 1999).
PARKER, A.C.J., and WHATLEY and SALCINES, JJ., Concur.
