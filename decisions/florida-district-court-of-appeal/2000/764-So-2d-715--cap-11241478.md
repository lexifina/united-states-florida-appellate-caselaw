# Beasley v. State

## Majority (PER CURIAM.)

PER CURIAM.
We dismiss this appeal for lack of jurisdiction based upon appellant’s failure to timely file the notice of appeal. This disposition is without prejudice to appellant’s right to seek relief by petition for belated appeal in accordance with the procedures set forth in Florida Rule of Appellate Procedure 9.140(j).
DAVIS, BENTON and PADOVANO, JJ., concur.
