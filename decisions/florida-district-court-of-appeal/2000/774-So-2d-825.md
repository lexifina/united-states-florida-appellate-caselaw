# Williams v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm the circuit court’s order denying appellant’s motion for post-conviction relief, but we remand for correction of the written judgment which incorrectly reflects the statutes under which appellant was convicted.
STEVENSON, SHAHOOD and HAZOURI, JJ., concur.
