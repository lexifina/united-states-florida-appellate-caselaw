# Wolfe v. State

## Majority (PER CURIAM.)

PER CURIAM.
This is a companion case to that of Sanders v. State of Florida, Fla.App., 184 So.2d 686, in which appellant likewise seeks an order of this court granting to.him bail pending appeal. For the reasons set forth in the Sanders case, the application of ap-' pellant is denied.
RAWLS, C. J., and WIGGINTON and CARROLL, DONALD K.,JJ., concur.
