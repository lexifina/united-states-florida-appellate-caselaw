# Schlee v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm appellant’s conviction but remand for sentencing correction. The written sentence must be corrected to reflect the trial court’s oral pronouncement that appellant should be sentenced as a youthful offender. See Kelly v. State, 414 So.2d 1117 (Fla. 4th DCA 1982).
GLICKSTEIN, C.J., and STONE and FARMER, JJ., concur.
