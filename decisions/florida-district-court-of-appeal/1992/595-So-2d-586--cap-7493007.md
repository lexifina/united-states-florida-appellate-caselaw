# Wright v. State

## Majority (HARRIS, Judge.)

HARRIS, Judge.
We affirm the conviction arid sentence of David Lamar Wright. However, this cause is remanded to correct the scoresheet which improperly scored “legal constraint.” See Flowers v. State, 586 So.2d 1058 (Fla. 1991).
AFFIRMED and REMANDED to correct scoresheet.
DAUKSCH and PETERSON, JJ., concur.
