# Black v. State

## Majority (PER CURIAM.)

PER CURIAM.
Roger Black appeals his guideline sentence and order of restitution for the offense of burglary with a battery. We affirm the sentence, except that portion relating to restitution, which we vacate, in that it is a duplication of the restitution ordered in case number 90-1517, which arises from the same transaction as the instant case.
AFFIRMED IN PART, VACATED IN PART.
ERVIN, WIGGINTON and KAHN, JJ., concur.
