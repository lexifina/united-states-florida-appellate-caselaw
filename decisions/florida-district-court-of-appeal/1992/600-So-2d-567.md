# Severino v. Priest

## Majority (PER CURIAM.)

PER CURIAM.
This is an appeal from an order granting the plaintiff a new trial after a defense verdict in a personal injury action. No error or abuse of discretion has been demonstrated. See Cloud v. Fallis, 110 So.2d 669 (Fla.1959); Seaboard Coastline R.R. Co. v. Zufelt, 280 So.2d 723 (Fla. 1st DCA 1973).
Affirmed.
