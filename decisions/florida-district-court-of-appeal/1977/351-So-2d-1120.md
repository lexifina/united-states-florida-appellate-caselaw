# Rosen v. Bauman

## Majority (PER CURIAM.)

PER CURIAM.
On appeal is an interlocutory order granting an evidentiary hearing in a mortgage foreclosure case subsequent to Judgment. We affirm the Order granting the eviden-tiary hearing.
AFFIRMED.
