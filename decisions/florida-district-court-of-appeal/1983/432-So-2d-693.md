# Graydon v. State

## Majority (PER CURIAM.)

PER CURIAM.
We find error only in assessment of costs. Costs should be stricken and judgment be corrected against the indigent defendant. See Brown v. State, 427 So.2d 271 (Fla. 2d DCA 1983) (question certified).
In all other aspects this case is affirmed. See McCrae v. State, 395 So.2d 1145 (Fla. 1981), and Salvatore v. State, 366 So.2d 745 (Fla.1978).
SCHEB, A.C.J., and RYDER and DAN-AHY, JJ., concur.
