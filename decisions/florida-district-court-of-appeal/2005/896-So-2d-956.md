# Thomas v. State

## Majority (PER CURIAM.)

PER CURIAM.
This appeal is dismissed for lack of jurisdiction. See Jordan v. State, 549 So.2d 805 (Fla. 1st DCA 1989). This dismissal is without prejudice to appellant’s right to file a petition for belated appeal. See Proctor v. State, 845 So.2d 1007 (Fla. 5th DCA 2003).
VAN NORTWICK, POLSTON and THOMAS, JJ., concur.
