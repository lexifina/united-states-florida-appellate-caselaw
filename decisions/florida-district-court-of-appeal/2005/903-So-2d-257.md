# Rivera v. State

## Majority (PER CURIAM.)

PER CURIAM.
Affirmed. See Burrows v. State, 890 So.2d 286 (Fla. 2d DCA 2004); Teal v. State, 862 So.2d 871 (Fla. 2d DCA 2003), review granted, No. SC04-102, 898 So.2d 81, 2005 WL 937725 (Fla. Apr. 1, 2005); McCall v. State, 862 So.2d 807 (Fla. 2d DCA 2003); Robbins v. State, 816 So.2d 783 (Fla. 2d DCA 2002); Cook v. State, 816 So.2d 773 (Fla. 2d DCA 2002); Collins v. State, 800 So.2d 660 (Fla. 2d DCA 2001); Patterson v. State, 796 So.2d 572 (Fla. 2d DCA 2001); Shaw v. State, 780 So.2d 188 (Fla. 2d DCA 2001); Enriquez v. State, 885 So.2d 892 (Fla. 3d DCA 2004); LaMar v. State, 823 So.2d 231 (Fla. 4th DCA 2002).
As this court did in Teal and McCall, we certify direct conflict with Richardson v. State, 884 So.2d 950 (Fla. 4th DCA 2003), review granted, No. SC04-174, 898 So.2d 81, 2005 WL 937726 (Fla. Apr. 1, 2005).
Affirmed; conflict certified.
ALTENBERND, C.J., and SALCINES and SILBERMAN, JJ., Concur.
