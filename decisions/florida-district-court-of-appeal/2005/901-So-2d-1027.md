# J.F. v. State

## Majority (PER CURIAM.)

PER CURIAM.
We reverse an order of restitution because there was no sworn testimony by the victim, and because the defendant did not have the opportunity to be present. We remand for a proper hearing.
WARNER, KLEIN and TAYLOR, JJ., concur.
