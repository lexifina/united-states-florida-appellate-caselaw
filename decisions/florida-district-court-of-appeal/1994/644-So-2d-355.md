# Coleman v. State

## Majority (PER CURIAM.)

PER CURIAM.
We vacate the habitual offender sentences imposed in this case and remand this cause for resentencing. See Santoro v. State, 644 So.2d 585 (Fla. 5th DCA 1994); Thompson v. State, 638 So.2d 116 (Fla. 5th DCA 1994). See also Cole v. State, 640 So.2d 1194 (Fla. 1st DCA 1994).
Sentences VACATED; cause REMANDED.
PETERSON, DIAMANTIS and THOMPSON, JJ., concur.
