# Varveris v. Schenker

## Majority (PER CURIAM.)

PER CURIAM.
Appellants/petitioners appeal an order granting an injunction and petition for a writ of certiorari to review an order denying authorization to notice an annual meeting for the Davis Gardens Homeowners’ Association.
We deny certiorari and affirm all points on appeal except for the trial court’s failure to set bond. Appellants are entitled to have the trial court set a bond on remand. Fla. R.Civ.P. 1.610(b).
Affirmed in part; remanded in part; cer-tiorari denied.
