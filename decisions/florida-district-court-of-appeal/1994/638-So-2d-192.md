# In re for Petition Name Change from Gessner to Spagone

## Majority (PER CURIAM.)

PER CURIAM.
In this appeal from an order denying a prisoner’s petition for a name change, we reverse the order of denial and remand for further proceedings. See In re Petition for Name Change from Boyd to Coon, 627 So.2d 30 (Fla. 2d DCA 1993).
RYDER, A.C.J., and PARKER and PATTERSON, 33., concur.
