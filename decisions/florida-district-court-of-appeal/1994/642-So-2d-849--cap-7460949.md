# Lainez v. State

## Majority (PER CURIAM.)

PER CURIAM.
Defendant appeals an order revoking his community control and imposing sentence. We affirm the order revoking community control; however, we strike the written reasons. We modify the order to reflect that defendant violated community control by failing to appear for scheduled program meetings, thereby conforming the written order to the court’s oral pronouncements. Villanueva v. State, 637 So.2d 350 (Fla. 3d DCA 1994).
Affirmed as modified.
