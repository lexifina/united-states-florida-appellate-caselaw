# Ferenc v. Wade

## Majority (PER CURIAM.)

PER CURIAM.
We have for review an order dismissing John M. Ferenc’s action, for failure to prosecute. The trial court erroneously dismissed Ferenc’s action “with prejudice.” Harrison v. Griffin, 443 So.2d 499 (Fla. 1st DCA 1984). We therefore strike these words from the order of the trial court. The order of the trial court is affirmed in all other respects.
It is so ordered.
ALLEN, WEBSTER and LAWRENCE, JJ., concur.
