# Roberts v. Roberts

## Majority (EMAS, J.)

EMAS, J.
We reverse the March 27, 2012, order awarding $600 in attorney’s fees to Henry M. Bugay, and remand for the trial court to set forth the basis for the award, and, if imposed as a sanction, to set forth the necessary findings to support the award. See Moakley v. Smallwood, 826 So.2d 221 (Fla.2002). We affirm in all other respects the orders under review.
