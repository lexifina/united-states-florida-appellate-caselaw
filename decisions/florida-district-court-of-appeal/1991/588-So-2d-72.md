# State v. Forrest

## Majority (PER CURIAM.)

PER CURIAM.
Reversed and remanded for further proceedings in accord with this court’s opinion in State v. Baxter, 581 So.2d 937 (Fla. 4th DCA 1991). We also certify the issue as one of great public importance as we did in State v. Scates, 585 So.2d 385 (Fla. 4th DCA 1991). We do not restate the issue since it is set out in full in Scates.
GLICKSTEIN, C.J., ANSTEAD, J., and OFTEDAL, RICHARD L., Associate Judge, concur.
