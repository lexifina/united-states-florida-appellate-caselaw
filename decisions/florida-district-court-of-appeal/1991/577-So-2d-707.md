# Brooks v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm appellant’s judgment and sentence except for the imposition of costs and attorney’s fees, which we set aside. If the state seeks to impose costs and attorney’s fees on remand, it must provide notice and an opportunity to be heard.
SCHOONOVER, C.J., and CAMPBELL and THREADGILL, JJ., concur.
