# Whittaker v. Ellison

## Majority (PER CURIAM.)

PER CURIAM.
The record more than amply supports appellant’s argument relating to excusable neglect. Accordingly, it was error for the trial court to deny appellant’s Motion to Set Aside the Default. See B. C. Builders Supply Co., Inc. v. Maldonado, 405 So.2d 1345 (Fla. 3d DCA 1981).
Reversed.
