# Torres v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm the order denying post-conviction relief. See Hernandez-Molina v. State, 860 So.2d 483 (Fla. 4th DCA 2003). We again certify conflict with Taylor v. State, 818 So.2d 544 (Fla. 2d DCA), review dismissed, 821 So.2d 302 (Fla.2002).
