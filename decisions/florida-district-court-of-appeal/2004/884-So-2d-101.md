# Pruitte v. State

## Majority (PER CURIAM.)

PER CURIAM.
Affirmed. See Teal v. State, 862 So.2d 871 (Fla. 2d DCA 2003); McCall v. State, 862 So.2d 807 (Fla. 2d DCA 2003). As this court did in both Teal and McCall, we certify direct conflict with Richardson v. State, 884 So.2d 950, 2003 WL 21697171 (Fla. 4th DCA July 23, 2003).
