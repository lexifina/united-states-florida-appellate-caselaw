# Chapman v. State

## Majority (PER CURIAM.)

PER CURIAM.
We treat this appeal as a petition for writ of certiorari. The petition is denied. See State v. Harris, 881 So.2d 1079 (Fla.2004); Murray v. Regier, 872 So.2d 217 (Fla.2002); and State v. Klein, 851 So.2d 274 (Fla. 5th DCA 2003).
PETITION DENIED.
