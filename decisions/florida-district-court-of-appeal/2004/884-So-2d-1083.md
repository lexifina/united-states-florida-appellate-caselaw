# Schmidt v. Crosby

## Majority (PER CURIAM.)

PER CURIAM.
We dismiss this appeal as being taken from nonñnal, nonappealable orders. Because there is no basis for granting either mandamus or prohibition relief, appellant’s request that we treat the appeal as invoking the court’s jurisdiction to issue those extraordinary writs is denied.
ALLEN, VAN NORTWICK and BROWNING, JJ., concur.
