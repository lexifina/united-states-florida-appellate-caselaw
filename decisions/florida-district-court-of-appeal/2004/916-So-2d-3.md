# Bonilla v. State

## Majority (PER CURIAM.)

PER CURIAM.
Affirmed. See Gipson v. State, 616 So.2d 992 (Fla.1993); McCall v. State, 862 So.2d 807 (Fla. 2d DCA 2003); Collins v. State, 800 So.2d 660 (Fla. 2d DCA 2001); State v. Kinney, 670 So.2d 1093 (Fla. 2d DCA 1996); Martin v. State, 795 So.2d 143 (Fla. 3d DCA 2001).

Affirmed; conflict certified.
