# Bateman v. State

## Majority (PER CURIAM.)

PER CURIAM.
This is an appeal from the trial court’s denial of the defendant’s motion to modify her sentence, pursuant to Florida Rule of Criminal Procedure 3.800(c). The State correctly argues that the order is not ap-pealable. Lee v. State, 662 So.2d 731 (Fla. 2d DCA 1995). The appeal is therefore dismissed.
STEVENSON, SHAHOOD and MAY, JJ., concur.
