# State v. Velasquez

## Majority (PER CURIAM.)

PER CURIAM.
The State appeals an order dismissing an information because it failed to produce witnesses for a deposition.
We reverse upon the authority of State v. Roig, Fla.App.1974, 305 So.2d 836, and return the matter to the trial court for further proceedings.
Reversed and remanded, with directions.
