# D.C. v. State

## Majority (PER CURIAM.)

PER CURIAM.
The restitution order appealed in this case is the same order at issue in D.C. v. State, 109 So.3d 1264 (Fla. 2d DCA 2013). For the reasons expressed in D.C., we reverse and remand for a new evidentiary hearing.
Reversed and remanded.
CASANUEVA, DAVIS, and BLACK, JJ., Concur.
