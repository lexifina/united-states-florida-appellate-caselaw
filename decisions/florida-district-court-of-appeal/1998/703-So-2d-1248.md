# Ellison v. State

## Majority (PER CURIAM.)

PER CURIAM.
AFFIRMED. The issue raised by the appellant was considered and rejected in Ellison v. State, 659 So.2d 1101 (Fla. 5th DCA 1995). Rule 3.800(a) cannot be used to rear-gue the same ground. See., e.g., Hall v. State, 690 So.2d 754 (Fla. 5th DCA 1997).
DAUKSCH, PETERSON and THOMPSON, JJ., concur.
