# State v. Bates

## Majority (PER CURIAM.)

PER CURIAM.
Pursuant to Florida Rule of Appellate Procedure 9.315(b), this case is summarily reversed. See State v. Hayes, 720 So.2d 1095, 1096 (Fla. 4th DCA 1998) and Johnson v. State, 23 Fla. L. Weekly D2419, D2420, — So.2d —, —(Fla. 4th DCA Oct.28, 1998). As we did in Hayes and Johnson, we certify conflict with State v. Holland, 689 So.2d 1268 (Fla. 1st DCA 1997) and State v. Perry, 716 So.2d 327 (Fla. 2d DCA 1998).
GUNTHER, WARNER and STEVENSON, JJ., concur.
