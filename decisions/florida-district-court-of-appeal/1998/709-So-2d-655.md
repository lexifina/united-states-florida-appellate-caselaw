# Gibson v. State

## Majority (PER CURIAM.)

PER CURIAM.
AFFIRMED. See Hammond v. State, 702 So.2d 637 (Fla. 1st DCA 1997); Johnson v. State, 536 So.2d 1009 (Fla.1988) (absent any exception to the time limitation, persons whose judgment and sentence became final prior to January 1, 1985, had until January 1, 1987, to file a 3.850 motion).
