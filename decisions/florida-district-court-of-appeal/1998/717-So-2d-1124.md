# State v. J.M.H.

## Majority (PER CURIAM.)

PER CURIAM.
The order denying the state’s motion to suspend the child’s driving privileges is reversed. State v. M.A.P., 708 So.2d 322 (Fla. 2d DCA 1998); State v. M.D., 706 So.2d 41 (Fla. 2d DCA 1998); State v. R.N., 597 So.2d 862 (Fla. 5th DCA 1992).
REVERSED and REMANDED.
GRIFFIN, C.J., and COBB and THOMPSON, JJ., concur.
