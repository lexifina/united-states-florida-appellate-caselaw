# Stone v. State

## Majority (PER CURIAM.)

PER CURIAM.
As to the request for grand jury minutes, see section 905.24, Florida Statutes (1995); State v. Reese, 670 So.2d 174 (Fla. 4th DCA 1996); State v. Pleas, 659 So.2d 700 (Fla. 1st DCA 1995). As to the disqualification of a judge, see Fischer v. Knuck, 497 So.2d 240 (Fla.1986).
AFFIRMED.
PETERSON, C.J., and HARRIS and ANTOON, JJ., concur.
