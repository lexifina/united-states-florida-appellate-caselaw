# Shiver v. State

## Majority (PER CURIAM.)

PER CURIAM.
The state having properly agreed that error occurred in the trial court, we reverse the order of restitution for unrecovered property allegedly taken during a burglary unrelated to appellant and remand for such correction.
GLICKSTEIN, GUNTHER and POLEN, JJ., concur.
