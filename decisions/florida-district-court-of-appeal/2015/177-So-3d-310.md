# State v. K.M.

## Majority (PER CURIAM.)

PER CURIAM.
We reverse the trial court’s order dismissing the state’s delinquency petition prior to an adjudicatory hearing and remand for further proceedings. See State v. J.C., 141 So.3d 756, 757 (Fla. 4th DCA 2014); State v. W.D., 112 So.3d 702, 704 (Fla. 4th DCA 2013).
GROSS, TAYLOR, JJ., and SHEPHERD, CAROLINE, Associate Judge, concur.
