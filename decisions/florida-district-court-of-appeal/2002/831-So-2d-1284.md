# Opsincs v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm as to all issues raised. As to appellant’s second issue, we affirm based on Couzo v. State, 830 So.2d 177 (Fla. 4th DCA 2002) and Miller v. State, 828 So.2d 445 (Fla. 4th DCA 2002).
AFFIRMED.
