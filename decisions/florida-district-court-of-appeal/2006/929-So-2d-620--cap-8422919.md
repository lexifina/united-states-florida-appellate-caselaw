# Echevarria v. State

## Majority (PER CURIAM.)

PER CURIAM.
On this appeal from convictions and sentences for first degree murder and associated crimes committed during a home invasion armed robbery, we find no error and affirm with the exception of requiring the correction of a scrivener’s error in the judgment as to count 3 consistent with the jury verdict. The defendant need not be present.
Affirmed as modified.
