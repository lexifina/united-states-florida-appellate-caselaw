# Bing v. State

## Majority (PER CURIAM.)

PER CURIAM.
All issues raised in the appellant’s “Motion to Correct Sentence” in case number 1D05-1375, and “Petition for Writ of Ha-beas Corpus” in case number 1D05-1704, have been considered and the trial court’s orders denying relief in both cases are hereby affirmed.
AFFIRMED.
KAHN, C.J., BROWNING and THOMAS, JJ., concur.
