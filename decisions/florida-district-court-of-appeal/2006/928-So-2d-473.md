# Lightbourne v. State

## Majority (PER CURIAM.)

PER CURIAM.
Hartman Lightbourne seeks a second belated appeal from a judgment and sentence rendered January 31, 2005. This court denies the second petition for belated appeal. See Lightbourne v. State, 920 So.2d 776 (Fla. 3d DCA 2006).
