# Bennett v. Dempsey & Goldsmith, P.A.

## Majority (COBB, Judge.)

COBB, Judge.
The default must be set aside and the corresponding final judgment predicated thereupon vacated because the defendant served a responsive pleading on the same day the default was entered. See Nasrallah v. Smith, 538 So.2d 554 (Fla. 5th DCA 1989); Roche v. Commercial Technical Consultants Co., 534 So.2d 1243 (Fla. 5th DCA 1988).
REVERSED.
HARRIS, C.J., and DAUKSCH, J., concur.
