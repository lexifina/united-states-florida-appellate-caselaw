# Sims v. Nazir

## Majority (PER CURIAM.)

PER CURIAM.
In the eviction proceeding below, we reverse the trial court’s order finding that it is contrary to the summary procedure set forth in section 51.011, Florida Statutes (2002).
Reversed and remanded for further proceedings.
