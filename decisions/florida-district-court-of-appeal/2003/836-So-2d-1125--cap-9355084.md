# Bentley v. State

## Majority (PER CURIAM.)

PER CURIAM.
The State properly concedes that the defendant is entitled to an additional 201 days credit for time served in case no. 97-32886. We agree with the State that the defendant’s remaining points lack merit. Gethers v. State, 838 So.2d 504 (Fla.2003).
