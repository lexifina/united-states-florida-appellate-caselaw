# State v. Ortiz

## Majority (PER CURIAM.)

PER CURIAM.
The State of Florida appeals from a trial court order dismissing a felony information against Jose Adriano Ortiz. We reverse the order of dismissal. See Fla. R.Crim. P. 3.191(b).
Reversed.
