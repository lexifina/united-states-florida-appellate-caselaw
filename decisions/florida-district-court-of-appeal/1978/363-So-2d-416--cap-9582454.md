# Churruca v. Miami Jai Alai, Inc.

## Majority (PER CURIAM.)

PER CURIAM.
Appellants question the correctness of the trial court’s order severing the action against defendant/appellee, Volusia Jai Alai, Inc., and transferring the same to the Circuit Court of Volusia County, Florida.
Prior to the filing of its brief, the appel-lee filed a request herein that the order appealed be reversed, inasmuch as the point on appeal is confessed to be meritorious.
Therefore the order appealed is reversed.
Reversed.
