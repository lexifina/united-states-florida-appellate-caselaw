# Alcantaro v. State

## Majority (PER CURIAM.)

PER CURIAM.
Appellant appeals from a nonfinal order which is not appealable under Florida Rule of Appellate Procedure 9.130(a)(3). So that we could address the merits of this appeal we converted the appeal into a petition for certiorari.
Certiorari denied.
RYDER, Acting C. J., and DANAHY and CAMPBELL, JJ., concur.
