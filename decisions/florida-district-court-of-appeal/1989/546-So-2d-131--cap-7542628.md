# Universal Sun Development Co. v. Stewart

## Majority (PER CURIAM.)

PER CURIAM.
Based on the appellee’s confession of error filed in this cause, the order denying the appellant’s motion to set aside default — which is under review by this appeal — is reversed and the cause is remanded to the trial court with directions to grant the aforesaid motion.
Reversed and remanded.
