# Smith v. State

## Majority (DAUKSCH, Judge.)

DAUKSCH, Judge.
The judgment appealed is affirmed. We certify, as we did in Morrow v. State, 547 So.2d 1236 (Fla. 5th DCA 1989), the following question to be of great public importance:
IS SECTION 893.13(l)(e), FLORIDA STATUTES (1987) CONSTITUTIONAL?
AFFIRMED.
DANIEL, C.J., and COWART, JJ., concur.
