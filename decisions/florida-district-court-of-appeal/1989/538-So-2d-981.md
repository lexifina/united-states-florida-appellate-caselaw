# Paz v. State

## Majority (PER CURIAM.)

PER CURIAM.
The conviction under review for sale of cocaine is affirmed. The separate conviction for possession of the same contraband is vacated and set aside. Vargas v. State, (Fla. 3d DCA, opinion filed, February 14, 1989); Blanca v. State, 532 So.2d 1327 (Fla. 3d DCA 1988).
