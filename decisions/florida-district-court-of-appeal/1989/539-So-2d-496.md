# 557318 Ontario, Inc. v. Pines & Palms Properties, Inc.

## Majority (DAUKSCH, Judge.)

DAUKSCH, Judge.
This is an appeal from an order awarding attorneys fees. Because there is no record evidentiary support for the award and because there is no legal basis for the award it is reversed.
REVERSED.
SHARP, C.J., and GOSHORN, J., concur.
