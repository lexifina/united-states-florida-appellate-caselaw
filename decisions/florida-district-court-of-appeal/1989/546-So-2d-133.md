# Guerra v. State

## Majority (PER CURIAM.)

PER CURIAM.
AFFIRMED. We do not address whether a mandatory fine should have been imposed upon appellant. We find the state waived such issue by failing to file a cross appeal. Fla.R.App.P. 9.110(g).
