# Joyner v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm all of the appellant’s convictions except for the possession of a firearm while engaged in a criminal offense conviction, which the state appropriately concedes to be duplicitous of appellant’s conviction for attempted first-degree murder and which we reverse.
GLICKSTEIN, GUNTHER and STONE, JJ., concur.
