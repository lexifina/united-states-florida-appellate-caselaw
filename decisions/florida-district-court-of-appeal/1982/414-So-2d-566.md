# Abreo v. State

## Majority (SHARP, Judge.)

SHARP, Judge.
Appellant’s conviction for manslaughter is supported by substantial, competent evidence and is affirmed. The weight to be afforded the evidence was properly an issue for the trier of fact. Tibbs v. State, 397 So.2d 1120 (Fla.1981).
AFFIRMED.
DAUKSCH, C. J., and COBB, J., concur.
