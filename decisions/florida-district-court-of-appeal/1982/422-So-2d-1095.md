# Fitzgerald v. State

## Majority (PER CURIAM.)

PER CURIAM.
This is an appeal from an order denying defendant’s motion to discharge based on speedy trial grounds. We conclude that error occurred and the defendant is hereby discharged. See Ex rel Butler v. Cullen, 253 So.2d 861 (Fla.1971).
REVERSED AND DISCHARGED.
DOWNEY, BERANEK and WALDEN, JJ., concur.
