# Palmer v. Palmer

## Majority (COWART, Judge.)

COWART, Judge.
We dismiss this appeal of an order granting a motion to set aside a default and vacating the default because that order is neither an appealable final judgment nor an appealable non-final order. See Yates v. Roller Skating Rinks, Inc., 379 So.2d 1333 (Fla. 5th DCA 1980).
DISMISSED.
DAUKSCH, C. J., and FRANK D. UP-CHURCH, Jr., J., concur.
