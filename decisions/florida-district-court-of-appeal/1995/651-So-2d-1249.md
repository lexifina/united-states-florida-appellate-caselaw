# State v. Harbeson

## Majority (PER CURIAM.)

PER CURIAM.
We grant the state’s petition for certiorari review of the trial court’s pretrial order excluding the state’s child victim hearsay evidence. See State v. Grego, 648 So.2d 743 (Fla. 2d DCA 1994), review denied, 651 So.2d 1194 (Fla.1995). The order is quashed and the case remanded for further proceedings.
THREADGILL, A.C.J., and BLUE and FULMER, JJ., concur.
