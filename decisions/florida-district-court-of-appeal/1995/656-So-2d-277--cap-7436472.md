# Glachman v. Residential Funding Corp.

## Majority (PER CURIAM.)

PER CURIAM.
This is an improvidently taken appeal from a non-appealable order severing a permissive counterclaim for damages from a foreclosure complaint. Treating the papers as an application for certiorari, we deny relief. Fla. R.Civ.P. 1.270(b); Bernstein v. Dwork, 320 So.2d 472 (Fla. 3d DCA 1975), cert. denied, 336 So.2d 599 (Fla.1976).
