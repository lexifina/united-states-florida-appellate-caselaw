# Milner v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm, but remand so that appellant’s sentences can be corrected to reflect that the sentence on Count III is to be served concurrently with the sentence on Count I, but not concurrently with the sentence on Count II.
GLICKSTEIN, GUNTHER and KLEIN, JJ., concur.
