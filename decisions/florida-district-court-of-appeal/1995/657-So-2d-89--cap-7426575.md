# Reynolds v. State

## Majority (PER CURIAM.)

CONFESSION OF ERROR
PER CURIAM.
The state having confessed error in the sentence under review as to the conviction on count three, said sentence is hereby set aside and vacated and the matter returned to the trial court for an appropriate sentence on said conviction.
