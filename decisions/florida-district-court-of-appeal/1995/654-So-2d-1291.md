# Morales v. State

## Majority (PER CURIAM.)

PER CURIAM.
The order denying appellant George Morales additional credit for time served is affirmed. The State’s contention that it is entitled to affirmative relief should be presented in the first instance in the trial court by appropriate motion.
Affirmed.
