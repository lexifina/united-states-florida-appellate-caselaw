# Christian v. State

## Majority (PER CURIAM.)

PER CURIAM.
The written judgment herein refers to a thirty-year sentence, whereas a thirty-month sentence was actually imposed. We remand for correction of this clerical error. Otherwise, we affirm.
SCHEB, A.C.J., and SCHOONOVER and FRANK, JJ., concur.
