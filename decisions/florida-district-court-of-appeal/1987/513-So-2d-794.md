# Fields v. State

## Majority (PER CURIAM.)

PER CURIAM.
For the reasons stated in Hardie v. State, 513 So.2d 791 (Fla. 4th DCA 1987) (which is being simultaneously released with this opinion), we reverse and remand this cause for a new trial.
REVERSED and REMANDED.
DOWNEY, DELL and STONE, JJ., concur.
