# State v. Villafane

## Majority (PER CURIAM.)

PER CURIAM.
This is a state appeal from a downward departure sentence. The appellee confessed error, and we accordingly vacate the sentence and remand for resentencing.
Sentence vacated; remanded for resen-tencing.
