# Freeze v. State

## Majority (PER CURIAM.)

PER CURIAM.
We agree with the state that this appeal was untimely filed. The trial court’s order denying deféndant’s petitions was rendered on September 29, 2000. The notice of appeal was filed on December 13, 2000.
The failure to file a notice of appeal within thirty days of rendition of the order being appealed presents an irremediable jurisdictional defect. See Rule 9.110(b), Fla.R.App.P. Accordingly, this appeal is dismissed.
