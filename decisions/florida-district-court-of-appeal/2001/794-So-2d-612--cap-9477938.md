# King v. State

## Majority (FULMER, Judge.)

FULMER, Judge.
The trial court’s order denying Timothy E. King’s motion filed pursuant to Florida Rule of Criminal Procedure 3.800 is affirmed without prejudice for King to file a Florida Rule of Criminal Procedure 3.850 motion pursuant to Murphy v. State, 773 So.2d 1174 (Fla. 2d DCA 2000) (en banc).
Affirmed.
PATTERSON, C.J., and BLUE, J., concur.
