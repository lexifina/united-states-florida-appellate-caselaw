# State v. Woods

## Majority (PER CURIAM.)

PER CURIAM.
Because the State failed to properly preserve its objection to the trial court’s imposition of the downward departure sentence, we affirm. See State v. Henriquez, 717 So.2d 1087 (Fla. 3d DCA 1998); State v. Rodriguez, 673 So.2d 187 (Fla. 3d DCA 1996).
Affirmed.
