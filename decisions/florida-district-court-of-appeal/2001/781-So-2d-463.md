# Wilkie v. State

## Majority (PER CURIAM.)

PER CURIAM.
The trial court’s order denying Scott Wilkie’s motion filed pursuant to Florida Rule of Criminal Procedure 3.800(a) is affirmed without prejudice to any right Wilkie might have to file a rule 3.850 motion. See Murphy v. State, 773 So.2d 1174 (Fla. 2d DCA 2000) (en banc).
Affirmed.
PARKER, A.C.J., and NORTHCUTT and SALCINES, JJ., concur.
