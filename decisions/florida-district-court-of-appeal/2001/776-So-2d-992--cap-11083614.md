# Levine v. State

## Majority (PER CURIAM.)

PER CURIAM.
Because the State concedes error, we reverse and remand for resentencing. The State acknowledges that the Appellant was entitled to be present at a resentenc-ing hearing resulting from the application of Heggs v. State, 759 So.2d 620 (Fla.2000).
GUNTHER, POLEN and TAYLOR, JJ., concur.
