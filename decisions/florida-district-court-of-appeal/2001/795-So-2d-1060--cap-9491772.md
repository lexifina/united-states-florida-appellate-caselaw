# Adams v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm appellant’s convictions, finding no error, but remand for correction of a scrivener’s error in the judgment which lists a conviction for count II, which the state concedes is incorrect.
WARNER, KLEIN and SHAHOOD, JJ., concur.
