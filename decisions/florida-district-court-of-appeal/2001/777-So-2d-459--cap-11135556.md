# Gibson v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm appellant’s convictions. We remand only for correction of the sentence for count two, resisting a law enforcement with violence. This crime is a third degree felony for which the statutory penalty is five years.
FARMER, KLEIN, TAYLOR, JJ., concur.
