# State v. Burrs

## Majority (PER CURIAM.)

PER CURIAM.
The state appeals a non-final order which suppresses in-court identification of the accused. We treat the appeal as a petition for certiorari, and deny it. See State v. Walker, 429 So.2d 1301 (Fla. 4th DCA 1983).
ANSTEAD, C.J., and GLICKSTEIN and DELL, JJ., concur.
