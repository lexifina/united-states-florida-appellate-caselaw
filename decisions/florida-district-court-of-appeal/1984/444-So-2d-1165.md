# Zanders v. Brown

## Majority (PER CURIAM.)

PER CURIAM.
Because the record in this partition action involving a single family residence does not support the extraordinary relief that has been granted, we reverse the trial court’s order appointing a receiver. See Electro Mechanical Products, Inc. v. Bor-ona, 324 So.2d 638 (Fla. 3d DCA 1976).
Reversed.
