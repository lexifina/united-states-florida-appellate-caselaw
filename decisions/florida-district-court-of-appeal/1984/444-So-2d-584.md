# Palm Beach Crown Liquors v. Smith

## Majority (PER CURIAM.)

PER CURIAM.
The deputy commissioner’s order sub ju-dice contains a scrivener’s error. Paragraph number 1 in the decretal portion of the order awards wage loss benefits from December 1, 1980. The correct date for the commencement of wage loss benefits should be December 1, 1982, and the order is hereby modified to reflect the correct date. As modified, the order is
AFFIRMED.
SHIVERS, JOANOS and THOMPSON, JJ., concur.
