# Landeverde v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm the trial court’s order that denied Landeverde’s motion. We agree with the second district that Spera v. State, 971 So.2d 754 (Fla.2007) does not apply retroactively. See Davis v. State, — So.2d-, 2008 WL 508654 (Fla. 2d DCA Feb. 27, 2008).
POLEN, HAZOURI and DAMOORGIAN, JJ., concur.
