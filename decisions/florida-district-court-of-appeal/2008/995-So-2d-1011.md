# Martinez v. State

## Majority (PER CURIAM.)

PER CURIAM.
DENIED. See Waterhouse v. State, 792 So.2d 1176, 1193 (Fla.2001) (stating that “this Court has repeatedly held that ineffective assistance of postconviction counsel is not a cognizable claim”).
