# State v. Tessier

## Majority (PER CURIAM.)

PER CURIAM.
We reverse an order granting Tessier’s motion to suppress evidence for reasons set out in the co-defendant’s appeal, State v. Powers, 991 So.2d 1040 (Fla. 4th DCA 2008).
We remand for further proceedings.
STONE, GROSS and TAYLOR, JJ., concur.
