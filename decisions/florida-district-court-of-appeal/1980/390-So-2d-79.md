# State v. Kimball

## Majority (PER CURIAM.)

PER CURIAM.
We reverse the trial court’s dismissal of the information in this case since the State filed a traverse which placed material facts in issue. See State v. Sanders, 380 So.2d 1126 (Fla. 2d DCA 1980).
The cause is REVERSED and REMANDED for further proceedings consistent with this opinion.
ANSTEAD, BERANEK and HURLEY, JJ., concur.
