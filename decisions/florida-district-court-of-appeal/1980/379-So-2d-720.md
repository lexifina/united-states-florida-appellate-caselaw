# State v. Gallego

## Majority (PER CURIAM.)

PER CURIAM.
This is an appeal by the state from an order excluding a witness from testifying at the trial because he did not attend a deposition set by the defendant. The defendant-appellee has confessed error in the order under review. Upon consideration of the confession of error, the brief of appellant, and the record, the order below is
Reversed.
