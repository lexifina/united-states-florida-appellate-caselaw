# Real v. State

## Majority (PER CURIAM.)

PER CURIAM.
As there is no showing in appellant’s motion that the public records were requested from the custodian, see Provenzano v. Dugger, 561 So.2d 541, 547 (Fla.1990), the order denying relief is affirmed, without prejudice to appellant to make a proper public records request to the custodian(s) thereof.
