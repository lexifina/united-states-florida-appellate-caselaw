# J.M.V. v. State

## Majority (PER CURIAM.)

PER CURIAM.
The restitution order which included an amount for the victim’s lost wages for attending the restitution hearing is reversed on the authority of J.S. v. State, 717 So.2d 175 (Fla. 4th DCA 1998). On remand, an order should be entered for $180.00, the value of the stolen items.
WARNER, C.J., STONE and STEVENSON, JJ., concur.
