# Wilson v. State

## Majority (PER CURIAM.)

PER CURIAM.
AFFIRMED. See State v. Baxley, 684 So.2d 831 (Fla. 5th DCA 1996), rev. denied, 694 So.2d 737 (Fla.1997). Accord State v. Hayes, 720 So.2d 1095 (Fla. 4th DCA 1998). We certify conflict with State v. Holland, 689 So.2d 1268 (Fla. 1st DCA 1997), and State v. Perry, 716 So.2d 327 (Fla. 2d DCA 1998).
