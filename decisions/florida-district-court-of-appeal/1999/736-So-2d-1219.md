# State v. Sims

## Majority (PER CURIAM.)

PER CURIAM.
The petition for writ of certiorari is granted, and the circuit court’s order finding section 837.011(3), Florida Statutes, to be unconstitutional, is quashed. See State v. Ellis, 723 So.2d 187 (Fla.1998); State v. Sims, 720 So.2d 213 (Fla.1998).
ERVIN, WOLF and WEBSTER, JJ., CONCUR.
