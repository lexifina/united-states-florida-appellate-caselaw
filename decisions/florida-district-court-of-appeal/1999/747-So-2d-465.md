# Morris v. State

## Majority (PER CURIAM.)

PER CURIAM.
Having considered Appellant’s response to the order to show cause issued November 1, 1999, the appeal is hereby dismissed for lack of jurisdiction. See Owens v. State, 579 So.2d 311 (Fla. 1st DCA 1991). The dismissal is without prejudice to file a notice of appeal when a final written order is entered.
LAWRENCE, DAVIS, AND VAN NORTWICK, JJ„ CONCUR.
