# Metallides v. State

## Majority (PER CURIAM.)

PER CURIAM.
The only point presented and argued on this appeal is that the trial court erred in failing to tax as costs for an acquitted defendant the premium for a bond paid to secure his pretrial release. This point has been decided adversely to the position of the appellant. See Holton v. State, Fla. App.1975, 311 So.2d 711.
Affirmed.
