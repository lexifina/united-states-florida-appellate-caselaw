# Kelly v. Edge Group, P.A.

## Majority (PER CURIAM.)

PER CURIAM.
We deny the petition for writ of prohibition without prejudice to petitioner to raise the same issues on plenary appeal. See Bondurant v. Geeker, 499 So.2d 909 (Fla. 1st DCA 1986), rev. dismissed, 515 So.2d 214 (Fla.1987). Contra, see Brogan v. Mullins, 452 So.2d 940 (Fla. 5th DCA 1984).
ANSTEAD, LETTS and GARRETT, JJ., concur.
