# Jones v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm the trial court’s action in summarily denying Jones’s Rule 3.850 motion. The motion was legally insufficient. However, this affirmance is without prejudice to Jones’s filing a legally sufficient Rule 3.850 motion if he is so advised.
LETTS, DELL and WALDEN, JJ., concur.
