# Jones v. State

## Majority (PER CURIAM.)

PER CURIAM.
As there was sufficient evidence to support the jury’s verdict, the conviction of second degree murder is affirmed. See Presley v. State, 499 So.2d 64 (Fla. 1st DCA 1986); Hooker v. State, 497 So.2d 982 (Fla. 2d DCA 1986), review denied, 506 So.2d 1041 (Fla.1987).
Affirmed.
