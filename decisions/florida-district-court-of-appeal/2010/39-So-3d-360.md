# Sanchez v. State

## Majority (PER CURIAM.)

PER CURIAM.
AFFIRMED. See Reeves v. State, 957 So.2d 625, 628 (Fla.2007) (holding trial court has discretion to impose Criminal Punishment Code sentence consecutive to Prison Releasee Reoffender sentence); see also Boyd v. State, 988 So.2d 1242, 1244 (Fla. 2d DCA 2008) (holding trial court correctly reclassified Prison Releasee Reoffender designation on one count to Criminal Punishment Code to prevent improper consecutive PRR sentences).
PADOVANO, THOMAS, and CLARK, JJ., concur.
