# Blanco v. State

## Majority (PER CURIAM.)

PER CURIAM.
Appellant’s conviction is affirmed. However, the State concedes error in the calculation of the sentencing guidelines seoresheet. Therefore, we remand only for recalculation of the sentencing guidelines seoresheet.
Affirmed in part; remanded with directions to recalculate the seoresheet.
