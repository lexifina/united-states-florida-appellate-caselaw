# Rodriguez v. State

## Majority (PER CURIAM.)

PER CURIAM.
We affirm the order denying defendant’s motion to correct illegal sentence and remand to the trial court to correct the sentencing sheet to reflect the judge’s oral pronouncement that this sentence was to run concurrent with defendant’s prior controlled release violation sentence.
