# McCutcheon v. State

## Majority (PER CURIAM.)

CONFESSION OF ERROR
PER CURIAM.
As the state has correctly conceded, section 790.08(3), Florida Statutes (1995) requires reversal of the order below denying the appellant’s motion for return of his firearms. Berkman v. State, 666 So.2d 606 (Fla. 3d DCA 1996); Tiller v. State, 650 So.2d 1134 (Fla. 4th DCA 1995); Cameiro v. State, 464 So.2d 639 (Fla. 3d DCA 1985).
Reversed.
