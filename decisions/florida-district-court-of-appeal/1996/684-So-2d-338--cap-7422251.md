# D.F. v. State

## Majority (PER CURIAM.)

PER CURIAM.
We reverse this juvenile adjudication for carrying a concealed weapon because the knife sharpener at issue was neither a weapon, State v. Tremblay, 642 So.2d 64 (Fla. 4th DCA 1994), nor concealed, State v. Hardy, 610 So.2d 38 (Fla. 6th DCA 1992), rev. denied, 621 So.2d 433 (Fla.1993).
POLEN, PARIENTE and GROSS, JJ., concur.
