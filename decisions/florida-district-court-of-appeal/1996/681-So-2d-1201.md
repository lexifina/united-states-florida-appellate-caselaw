# Rakers v. State

## Majority (PER CURIAM..)

PER CURIAM..
This court previously remanded this case for correction of several errors in the judgment. The trial judge entered an order correcting judgment from which Rakers appeals.
The order appealed from refers to the conviction as for violating Florida Statute 784.04(2). The correct statute is 782.04(2). We remand for correction of this scrivener’s error.
Otherwise, affirmed.
THREADGILL, C.J., and SCHOONOVER and WHATLEY, JJ., concur.
