# Robinson v. State

## Majority (HARRIS, Judge.)

HARRIS, Judge.
The State acknowledges error in that the trial court’s sentence did not give appellant credit for time served in prison on case number 92-34196 toward the sentence imposed in this case, in violation of Tripp v. State, 622 So.2d 941 (Fla.1993). We reverse for resentencing.
REVERSED AND REMANDED.
PETERSON, C.J., and ANTOON, J., concur.
