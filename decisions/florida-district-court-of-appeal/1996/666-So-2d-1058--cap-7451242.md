# Mediate v. State

## Majority (PER CURIAM.)

PER CURIAM.
AFFIRMED. See Davis v. State, 661 So.2d 1193, 1196-1197 (Fla.1995) (holding that defendant was precluded from raising issue of trial court’s failure to file contemporaneous written findings for departure in motion for postconviction relief unless defendant had raised issue in his appeal).
