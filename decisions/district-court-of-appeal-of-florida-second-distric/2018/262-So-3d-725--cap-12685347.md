# Batterbee v. State

## Majority

This appeal is dismissed for lack of jurisdiction because the circuit court order under review is a nonappealable order and no basis has been shown for invoking certiorari jurisdiction. See Tsikuris v. State, 913 So. 2d 1200 (Fla. 2d DCA2005) ; Sirmons v. State, 775 So. 2d 389 (Fla. 2d DCA 2000).
